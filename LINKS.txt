HOW TO RUN LOCALLY
-----------------------------------------------------------

Backend:
  cd backend
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  python train_model.py
  uvicorn app.main:app --reload

Frontend:
  cd frontend
  npm install
  npm run dev

Full setup details are in README.md.
